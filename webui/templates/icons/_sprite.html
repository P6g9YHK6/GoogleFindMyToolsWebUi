{# Self-hosted icon set, replacing the literal emoji glyphs the app used to render as button/status content. One per icon, referenced elsewhere via the icon() macro in _macros.html (). Included once by base.html right after so every page gets these defs for free without a network request or a build step - same outline style throughout (24x24 viewBox, stroke currentColor, no fill) so nothing looks mismatched next to anything else. Kept as one hidden inline SVG rather than an external .svg file: browsers only resolve reliably same-origin, and Safari in particular has a history of not following cross-document fragment references at all - inlining sidesteps that entirely. #}
