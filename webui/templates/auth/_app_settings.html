Apprise notifications

Sends a notification for every warning-or-worse logged anywhere in the app (locate failures, forwarding failures, sign-in failures, ...). See the apprise docs for the URL format (Discord, Telegram, email, ntfy, dozens more).

Devices page

Instead of listing every location from the last pull, show just the one with the latest timestamp (and only that one's map pin). Google can return several readings in one response - most people only want to see the newest.

Staleness page

Seconds. Independent of any device's own poll schedule - see the Staleness page, where each device's own alert threshold is set.

Semantic location mapping

Google reports a tracker as being at a named place (e.g. "Nest Mini - Living Room") instead of GPS coordinates when it's near one of your other Find My Network devices - with no coordinates, forwarding has nothing to send. Map a semantic name here to fixed coordinates and a matching reading is forwarded using them, still flagged as a semantic (not GPS) fix. With Full match the name must equal exactly what Google reports, case included; Partial match only requires it to appear somewhere in what Google reports, case-insensitively - check the Devices page or a Forwarding Log entry's payload for the exact text.
